# Panchikawatta Mobile Application — Frontend

A mobile marketplace application for buying and selling vehicle spare parts and services, including vehicle management and emergency assistance features.

## Tech Stack
- **Framework:** Flutter
- **Real-time Messaging & Storage:** Firebase (Firestore, Firebase Storage)

## Key Features
- Vehicle spare-parts and services marketplace
- Real-time chat between users, including media/file sharing via Firebase Storage
- User profile management
- Vehicle management and emergency assistance features

## Team
Built collaboratively by a 5-member team (TeamTechSamurais) as an academic group project.

## Project Status
Core features implemented, including the marketplace, real-time chat, and profile management. Refinements ongoing.
